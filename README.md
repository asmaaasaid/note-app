# 📝 Notify - Notes Management App

Notify is a modern **Notes Management Application** built using **Angular**.  
The application allows users to create an account, log in securely, and manage their personal notes using a full **CRUD system**.

It provides a smooth user experience with validation, toast notifications, confirmation dialogs, and search functionality.

---

# 🚀 Features

## 🔐 Authentication System
- User Signup with validation
- User Login with validation
- Secure Logout functionality
- Redirect to Login after logout

---

## 📝 Notes Management (CRUD System)

Users can:

- ➕ Add new notes  
- ✏️ Edit existing notes  
- 🗑️ Delete notes  
- ⚠️ Confirm before deleting notes  
- 🔍 Search notes by title  
- 📄 Write note title and description  

---

## 🔔 User Experience Features

- Toast notifications for actions  
- Confirmation dialog before delete  
- Form validation for authentication  
- Responsive UI design

# ⚙️ Installation & Setup

Follow these steps to run the project locally:

```bash
# Clone the repository
git clone https://github.com/asmaaasaid/note-app.git

# Navigate to project folder
cd notify-app

# Install dependencies
npm install

# Run the application
ng serve

# Then open
http://localhost:4200
